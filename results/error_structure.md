# 誤差の構造 — 復号の寄与と, 学習分布への引き (2026-09-29)

問い: 提案手法が radarODE-MTL に勝っているのは何によるか. 「山の形を使っている / いない」で説明できるか.
どちらも**再学習なし**. 保存済みの重み・窓ごとの予測だけを使う.

## 1. 提案手法は 40 ms 格子の上で, 山の形から格子の間を読んでいる

全 11 分割 91 試行 78,988 窓. 中央値フィルタなし, 正解は放物線補間した R 波位置 (`scratchpad/peak_shape.py`, s7 で実行).

| 復号 | 試行平均 MAE |
|---|---|
| argmax (ピークのビンの τ をそのまま) | **10.036 ms** |
| MODE±1 (ピーク ±1 ビンの局所期待値, 本番) | **6.499 ms** |
| EV (全ビンの期待値) | 6.564 ms |

- **argmax の 10.04 ms は, 一様量子化の理論値 Δ/4 = 10.0 ms とほぼ一致する**(Δ = 40 ms).
  つまり argmax で復号する限り, 信号がどれだけ良くてもここが床になる.
- 局所期待値にすると 6.50 ms. **内挿が 3.54 ms (35 %) を稼いでいる.**
- ピークのビンが正しい窓は 94.34 %. その窓のビン内残差 δ_true の平均は 7.43 ms (一様なら 10.0).
- **δ_pred = MODE±1 − argmax の τ** と **δ_true = 正解 − argmax の τ** の関係:
  - 相関 **0.794**
  - 回帰 **δ_true = 1.015·δ_pred + 0.001** ← 傾きがほぼ 1, 切片がほぼ 0. **δ_pred は δ_true の不偏推定になっている**
  - 内挿後の残差 |δ_true − δ_pred| の平均 4.02 ms (ビン内残差 7.43 → 4.02, 46 % 減)
- 外れた窓 (|δ_true| > 半ビン) は 5.66 % で, 誤差総量の 30.1 % を占める.

→ 「左右のバランス(山の形)を学んでいる」は定量的に裏づけられた. ただしこれは**我々自身が 40 ms 格子を使っていることの正当化**であって, radarODE-MTL との差の説明ではない(下記).

## 2. radarODE-MTL にとって山の形は律速でない

- PPI ヘッドのビン幅は **1 標本 = 5 ms** (200 Hz の整数サンプル 260 クラス).
- したがって完全な内挿でも救えるのは最大 Δ/4 = **1.25 ms**. 実測の誤差は 24 ms 級なので**量子化は律速していない**.
- 損失は `ecg_gts[b, counts-1] = 1000` → softmax → ワンホットの交差エントロピー
  (`Projects/radarODE_plus/utils/utils.py:24-35`). **クラスに順序が無く**, 復号は argmax.
  山の形は使っていないが, 使っても 1.25 ms しか変わらない.

## 3. 差の正体: 学習分布の平均への引き

窓ごとに e = 予測 − 正解, x = 正解 − その分割の学習側の平均 RR とし, e = β·x + c を当てた
(`scratchpad/prior_pull.py`, 91 試行 78,988 窓, 両手法とも同じ窓).

| | MAE(窓平均) | 符号つき平均 | **β** | 二乗誤差のうち引きで説明される割合 |
|---|---|---|---|---|
| radarODE-MTL (等重み, 20 ep) | 23.91 ms | +0.70 ms | **−0.208** | 16.1 % |
| 提案手法 (91131 相当) | 6.53 ms | −0.01 ms | **−0.019** | 1.2 % |

β = 0 なら正解がどこにあっても偏らない(信号から出している), β = −1 なら入力によらず学習平均を出す.
**radarODE-MTL の β は提案手法の 11 倍.**

試行の状態別(正解 RR 平均つき):

| 状態 | 正解 RR 平均 | radarODE-MTL MAE / 符号つき | 提案手法 MAE / 符号つき |
|---|---|---|---|
| NB (安静) | 857.6 ms | 15.78 / −4.19 | 5.45 / −0.03 |
| IB (不規則呼吸) | 854.2 ms | 31.63 / −2.74 | 8.08 / −1.16 |
| SP (発話) | 845.3 ms | 16.11 / −5.83 | 4.49 / −0.59 |
| **PE (運動後)** | **713.0 ms** | **53.14 / +33.15** | **11.13 / +2.65** |

PE の正解 RR は学習側の平均より約 132 ms 短い. β から予想される偏りは

- radarODE-MTL: 0.208 × 132 = **+27.5 ms** (実測 +33.15)
- 提案手法: 0.019 × 132 = **+2.5 ms** (実測 +2.65)

**どちらも実測とよく合う.** PE の崩れは「運動後だから雑音が多い」ではなく,
**正解が学習分布の端にあるとき出力が平均へ引かれる**という機構で説明できる.

## 4. ただし引きだけでは全部を説明しない

安静(NB)でも 15.78 対 5.45 で 3 倍の差がある. 引きは二乗誤差の 16 % にとどまる.
残りの説明は別に要る(前段 SST の位相破棄, 段数, 学習量など). **「事前分布への引き」を差の全部だと書かないこと.**

## 5. 書くときの注意

- 1 の量子化床の議論と 3 の引きの議論は**別の主張**. 混ぜない.
  1 は「なぜ我々が 40 ms 格子で済むか」, 3 は「なぜ相手が分布の端で崩れるか」.
- e を β·x で残差化した後の MAE (31.46 ms) は「引きを直したらこうなる」ではない.
  残差化は既に当たっている窓にも |β·x| を足すので MAE は増える. **説明率は分散で述べる.**
